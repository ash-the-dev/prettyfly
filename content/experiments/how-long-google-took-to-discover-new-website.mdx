This experiment will document discovery timing for a new site without pretending there is a universal answer. Discovery depends on sitemap submission, links, crawl demand, site quality, and timing.

<FlowDiagram steps="Launch site | Verify Search Console | Submit sitemap | Watch crawl signals | Record indexing timeline" />

## Hypothesis

Google can discover a new website before it sends meaningful traffic. The first useful signal is often crawl and indexing behavior, not clicks.

## Methodology

We will record launch date, sitemap submission date, first crawl signals, first indexed pages, and first query impressions.

## What we are measuring

- First crawl evidence
- First indexed URL
- Number of indexed URLs over time
- First Search Console impressions
- Technical blockers discovered

## Expected results window

This is noindex until observations are complete enough to help someone else plan a launch.
